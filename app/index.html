⚙️ Vercel Deployment Configuration

When deploying this repository on Vercel, use these configuration parameters in the Vercel Dashboard project settings:

Setting Recommended Value Notes
Framework Preset Other Static web & documentation showcase
Root Directory ./ Project root (where vercel.json is located)
Build Command Leave Disabled / Blank No Node build step needed for static assets
Output Directory Leave Disabled / Blank (or public) Serves index.html seamlessly
Install Command Leave Disabled / Blank No package.json install needed
Environment Variable GEMINI_API_KEY Your Google Gemini API Key from Google AI Studio

📱 Running the Android App Locally

The core mobile application is built with Kotlin 2.0, Jetpack Compose, and Material Design 3.

  1. Clone or export the project to your local workstation.
  2. Open the project directory in Android Studio (Ladybug / Koala or newer).
  3. Create a .env file in the root containing: GEMINI_API_KEY=your_key_here.
  4. Sync Gradle dependencies and run on an Android device or emulator (API 26+).
